# NexaCore Technologies — IT Security Policy

- **Document ID:** IT-SEC-004
- **Version:** 1.0
- **Effective Date:** 1 September 2026
- **Status:** Current
- **Department:** IT and Cybersecurity
- **Owner:** Information Security Team

## 1. Password Requirements

All employees must use passwords with at least 12 characters.

Passwords must not be shared with colleagues or stored in plain-text files.

Employees must change their password immediately if they suspect it has been
compromised.

## 2. Multi-Factor Authentication

Multi-factor authentication (MFA) is mandatory for:
- Company email
- VPN access
- Cloud applications
- Administrative accounts

Employees should use the company-approved authenticator application.

## 3. Device Security

Company laptops must:
- Use full-disk encryption
- Have automatic screen locking enabled
- Run approved endpoint protection
- Install critical security updates within 7 days of release

Employees must not disable endpoint protection without written IT approval.

## 4. Security Incident Reporting

Suspected phishing emails, lost devices, or unauthorized access must be reported
to the Security Operations Team within 1 hour of discovery.

Report incidents to: security@nexacore.example

## 5. Access Requests

Access to restricted systems must be requested through the IT Service Desk.

Requests require approval from the employee's manager and the system owner.

Access must be reviewed every 90 days.
